# Componentes de terceiros

- llama.cpp b10991: https://github.com/ggml-org/llama.cpp/blob/b10991/LICENSE — MIT.
- Qwen3.5 4B e 0.8B: https://huggingface.co/Qwen — Apache-2.0. Arquivos GGUF: https://huggingface.co/unsloth.
- cloudflared: https://github.com/cloudflare/cloudflared/blob/master/LICENSE — Apache-2.0.
- FastAPI, PyInstaller, pywebview, Uvicorn, HTTPX, psutil, Pillow, PyAutoGUI, pyperclip e qrcode: licenças distribuídas nos respectivos pacotes. PyInstaller permite distribuição dos aplicativos sob sua exceção de bootloader.

O projeto usa o servidor local llama.cpp compatível com o formato de chat completions. Isso não implica chamada a uma API de IA externa.
